# Project Scope

本工程只把冻结证据转化为可编码设计规范，不实现或调用闭环控制器。唯一主路线是：轴独立、双时间尺度、激励门控、S2 实际电压反馈、决策敏感区增强的一阶超局部预测器。

允许的工作是读取冻结上游、索引八篇论文、推导公式、定义状态与接口、编写断开的参考函数、执行合成数据单元测试、预注册下一原型。禁止修改 Zhou 控制器、S2、`Jd_limit/Jq_limit`、单/双/三矢量逻辑、候选生成、608 点扫描、sequence 分解、E1/E2 边界，也禁止当前工程运行 24 工况或闭环实验。

参考代码没有控制器入口、PWM 输出或 plant 依赖；`run_dual_timescale_design.m` 只做清单检查、静态文献/时序核验、合成信号计算和单元测试。

冻结上游以 `audit/SOURCE_PROJECTS.csv` 为唯一解析结果。约束审计工程实际位于嵌套目录，不能以同层目录假设替代。所有复制件均列在 `audit/COPIED_FILE_PROVENANCE.csv`，且源/目标 SHA256 相同。
