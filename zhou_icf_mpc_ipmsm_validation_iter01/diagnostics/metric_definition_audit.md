# Metric definition audit

Integer-cycle THD fields, aligned k+1/k+2 prediction endpoints, actual exceedance in amperes, separate selected/applied legality, torque components, voltage utilization, saturation, switching actions, and estimator/oracle errors are saved in every successful summary row. Failed rows retain metadata and the exact exception without borrowing metrics from another condition.

`illegal_command=1` means illegal. The legacy audit's inverted field is not reused. No plot smooths the data.
