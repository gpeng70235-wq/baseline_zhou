# Result interpretation rules

Facts require a passed gate and saved artifact. Inferences must be labeled. A transition association is not causality. The offline Oracle cannot be described as an online controller. ESO cannot be described as innovation. Parameter sensitivity cannot be translated into temperature/saturation behavior, and stress cases cannot be described as a real envelope.

Only one A–F outcome may appear in `VALIDATION_DECISION.md`. Any P0 mismatch, illegal high-speed/negative-id command, negative dwell, long saturation, or necessary Zhou-core rewrite triggers non-admission. A core test failure forbids a theoretical conclusion.
