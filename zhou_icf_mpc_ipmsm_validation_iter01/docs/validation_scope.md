# Validation scope

This project tests strict P0 inheritance, six P0/P1 conditions, common versus axis-specific input gain, negative `id`, plant-only parameter sensitivity, labeled stress cases, algebraic F versus basic ESO and an offline interval Oracle, residual associations, and numerical closure.

It does not design MTPA, redesign Case/duration/frame logic, claim hardware behavior, model temperature or saturation, or present ESO as novelty. Iteration 11 is a fixed validation source snapshot; its own final report explicitly withheld IPMSM admission.
