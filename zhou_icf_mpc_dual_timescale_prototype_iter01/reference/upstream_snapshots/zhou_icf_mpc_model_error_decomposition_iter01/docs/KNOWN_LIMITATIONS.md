# Known Limitations

1. **F/alpha gauge 不可辨识。** `F+alpha*u` 可在单一输入点重新参数化；独立份额只在真实 `1/L` + 物理漂移的 canonical gauge、当前输入覆盖和注册 Shapley 口径内成立。
2. **P2c/P3c 非因果。** 它们用 i(k+1) 反算当前平均 F，只是第一拍完美闭合的理论上界，不能部署，候选 ranking 也标 invalid。
3. **P1/P2a/P2b/P3a/P3b/P4 也不是现成控制器。** 它们需要真实参数、真实对象端点或物理状态，时间因果性不等于工程可实现性。
4. **P5 是同模型重放。** 它验证记录、积分和时间对齐，不证明现实电机未建模效应可以被 oracle 消除。
5. **候选 bank 非原生。** 离线 bank 是固定诊断集合，不等价于 Zhou 的连续矩形--六边形几何选择；top-1/mode 恢复不是主要 A--F 证据。
6. **相关性不等于因果。** 状态/残差、delta_F、alpha mismatch、S2、模式等相关表仅描述联合变化。
7. **频谱有效域有限。** 只有 `14/24` 个 case 被 case-level 标记为 steady-spectrum eligible；整数周期不足、基波过小或动态参考均不作谱结论。
8. **提前终止。** `5` 个场景只贡献终止前有效动态样本，不能假装有完整 steady window。
9. **简化对象。** 本轮主证据为定速、理想角度/测量、无 dead time/压降/噪声；torque ramp/step 是 dq current reference 映射，不是独立机械外环。
10. **参数覆盖有限。** Ld/Lq ±10%、组合与代表性 ±20% 是机理工况，不含无依据的剧烈随机跳变，也未建工作点饱和映射。
11. **固定约束与时域。** 结论只对 `Jd=Jq=0.16 A^2`、本次 `24` 场景和 `24153` 样本成立；没有重扫 Jd/Jq。
12. **下一算法未验证。** 结论映射出的 ESO/在线 alpha/高阶模型仍是假设，必须另建隔离工程再验证。
