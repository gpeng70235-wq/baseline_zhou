# Project Scope

## 研究问题

在相同闭环轨迹和相同 k→k+2 电压命令下，通过 P0--P5 逐级替换，判断独立 d/q 电流约束 false-safe 主要来自 F 估计、alpha 输入增益、两拍 F/状态冻结与显式 Euler，还是对象重放之外的实现问题。

## 范围内

- 五个冻结上游的只读盘点、逐文件 SHA256 和最小依赖复制。
- `24` 个具名工况、`24153` 个两拍对齐样本。
- P0/P1/P2a/P2b/P2c/P3a/P3b/P3c/P4/P5 离线预测、约束混淆、候选诊断、相关性和相干频谱。
- A--F 预注册门禁，只建议下一项目。

## 明确排除

- 不重扫 Jd/Jq；固定 `Jd_limit = Jq_limit = 0.16 A^2`。
- 不重新证明平均电压与逐段冻结-F 超局部预测的等价性。
- 不重新实现 E1/E2，不无条件收紧电流约束。
- 不修改原 Zhou 控制器，不在闭环中切换预测器。
- 不实现 ESO、RLS、在线参数辨识、神经网络、高阶或扩展仿射控制器。
- 不把 oracle 结果包装成部署方案。

## 完成定义

基线全过、P0/P5 对齐断言全过、注册 CSV 与 15 类图齐全、正式结论唯一、冻结上游变化为零。当前数据给出的唯一结论为 **C — F and alpha jointly dominate**。
