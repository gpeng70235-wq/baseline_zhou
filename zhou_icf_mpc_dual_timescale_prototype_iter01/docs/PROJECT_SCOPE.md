# Project Scope

Isolated implementation and gate validation of the frozen S2-aware dual-timescale ultralocal predictor.
The prototype may change only predictor/estimator state and predicted current. Plant, Ts=100 us, Jd/Jq=0.16 A^2, candidate generation, modes, S2 and termination semantics are frozen byte-identical copies.
The campaign stops after the failed five-case gate.
